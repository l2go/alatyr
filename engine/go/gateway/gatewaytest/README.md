# Gateway contract driver

The driver opens actual participant transports and decodes complete frames with
the published dictionary. Typed fixtures check admission, exact outcomes,
immutable terminal results, duplicate intents, malformed frames and appearance.
The world integration suite supplies the real authoritative source for G-series
scenarios, gameplay, reconnects and byte-for-byte deterministic replay.

Historical contract vectors remain under `testdata`; the direct adapter also
checks a frozen checkpoint, movement and authored-dialogue transcript captured
before removal of the previous source path. Participant codecs remain owned by
the protocol and meaning packages.
