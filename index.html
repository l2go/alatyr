Engineering

Six decisions, each held in place

A decision that nothing enforces is a wish. Each of these is checked by a rule, a test, or a step of the pipeline, linked below to the code of release 3.1.1.

I

One process, hard boundaries

Login and world share a JVM, not code. They meet only through a typed contract, and architecture rules fail the build on any other dependency. Each module has its own database role.

Enforced by ArchitectureTest, check-roles.sh
II

SQL checked against the schema

Every SQL statement in the compiled server is prepared against the migrated PostgreSQL schema, and every JDBC type is compared with its column. A ratchet keeps direct database access from spreading.

Enforced by GameServerStatementsPostgresTest, the ratchet
III

Every merge is a release rehearsal

The image starts, and 24 clients log in, create a character, enter the world, and log out. The server restarts, a backup is restored into a clean stack, and the published image is upgraded in place. The characters survive each step.

Enforced by build.yml, job image
IV

Releases promote, never rebuild

A release gives a version to the image digest that main built and tested, after the maintainer approves. The image carries a cosign signature, an SBOM, and provenance; the compose archive carries its own signature.

Enforced by release.yml
V

Hardened supply chain and runtime

Actions are pinned by commit, and Trivy blocks a release on a critical or high finding that has a fix. The container runs as user 10001 with a read-only root, no capabilities, and a 4 GB memory limit.

Enforced by compose.yaml, SECURITY.md
VI

Diagnosable in production

Java Flight Recorder keeps the last 12 hours. PostgreSQL counts every statement and logs the plan of any that runs over 500 ms. A health endpoint gates readiness, and a stop refuses new connections first.

Enforced by entrypoint, compose.yaml

Architecture

One process, one writer

The gatewayEach participant gets a bounded session behind a TLS proxy and a bearer token. Done needs a live world fact with its own cause; anything unproven ends as Unknown.
The worldOne simulation loop owns every change. Content loads from the authored files in the image, so the database holds characters, not content.
The databaseOne writer holds an advisory lease. Goose migrations only move forward, and a database with foreign objects is refused at start.

Chronicle

Nearly nine years of building, eleven of silence

Twenty-four people built it over nearly nine years. Twenty-four days rebuilt it. Twenty-four clients played every merge of its Java years. The history in the repository is the history of the code: 8,044 commits before the revival, and every pull request since then written as a small design record.

  1. 2006

    The first commit

    L2JFree begins in the L2J open-source community: a Lineage II server, written in Java, under the GPL.

  2. 2009

    Gracia Final

    The client this server speaks to. Its protocol, revision 83, is the one the Java server answers, through release 3.2.1.

  3. 2015

    Silence

    The last upstream commit lands on 15 July 2015. The code later moves to GitHub, where its repositories are archived as they were when work stopped.

  4. Sep 2026

    The revival

    A root build and CI on every push, then a correctness program that files each defect as a broken invariant. The server keeps its shape and moves to Java 25: 1.4.0 on 25 September, 2.0.0 on 30 September, 2.5.0 on 5 October.

  5. Oct 2026

    Platform 3.0 decided

    The 2.x line is retired, and the decisions for one process on PostgreSQL 18 are recorded. GitHub Actions is the only build of record.

  6. Oct 2026

    3.0.0

    Six days later: one process, PostgreSQL 18 with a schema and a role per module, a signed image, and a pipeline that plays it on every merge.

  7. Oct 2026

    3.1.0 and 3.1.1

    Economy and login defects closed by their invariants, a signature for the release archive, and a measured start.

  8. Oct 2026

    3.2.0

    The server leaves the inherited world behind and ships Okolitsa, an original world built by a Go tool from source files that use text keys. Monsters reward the players who fought them.

  9. Oct 2026

    3.2.1

    Native images for amd64 and arm64 on Debian 13, honest x1 rewards by default, and a new name and home: Alatyr, at l2go/alatyr.

  10. Oct 2026

    Go on main

    The Java runtime is retired on main. A Go server now owns the world, the participant gateway, and PostgreSQL persistence. Release 3.2.1 stays the last Java one; the first Go release opens the next series of notes.

Reviving L2JFree

Eight notes, one decision at a time: the problem, the decision, what it cost, and how it is checked. They follow the Java server from a codebase silent since 2015 to release 3.2.1; from 3.2 on, it runs a world of its own. The series is complete.

Two servers in one JVM, kept apart by a two-interface contract, eight dependency rules, and a database role per module.

An island of our own

Seventeen thousand files of an inherited world out, one island of our own in: a village, a meadow, and a tool that checks every word.

One save, one transaction

Starting a Java 25 server: G1, ZGC, and an AOT cache that did not help

Old bugs, new invariants

Predictable secrets, comparisons that stop early, lost updates, overflow, and operations that finish halfway: the class, the cause, and the check.

Trust, verified

Check what you run

  • The image is signed with cosign by the pipeline of main, with a short-lived certificate and no stored key.
  • It carries an SPDX SBOM and an SLSA build provenance.
  • The compose archive of a release carries the Sigstore bundle of its own provenance.
VERSION=3.2.1
cosign verify ghcr.io/l2go/l2jfree:$VERSION \
  --certificate-identity https://github.com/l2go/alatyr/.github/workflows/build.yml@refs/heads/main \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
gh attestation verify oci://ghcr.io/l2go/l2jfree:$VERSION --repo l2go/alatyr

gh release download v$VERSION --repo l2go/alatyr
gh attestation verify l2jfree-$VERSION-compose.tar.gz --repo l2go/alatyr \
  --bundle l2jfree-$VERSION-compose.tar.gz.sigstore.json \
  --signer-workflow l2go/alatyr/.github/workflows/release.yml
