Run

Run a server

One command starts the world, its gateway and its database. Before it does, you can check that the image is the one the project built and tested.

Start

Follow the deployment guide: put a TLS proxy in front, bind participant tokens to characters, and import the characters. Then:

cd deploy
docker compose up -d --wait

The image is ghcr.io/l2go/alatyr, for linux/amd64 and linux/arm64. There is no registration service: the operator owns the participant registry. Each deployment starts with a fresh database of its own.

Check what you run

Every image built on main is signed and carries build provenance. A release does not rebuild anything: it finds the image the pipeline already built and tested, verifies its signature and provenance, waits for a maintainer's approval and gives that same image a version.

gh attestation verify oci://ghcr.io/l2go/alatyr:5.0.0 --repo l2go/alatyr

The release bundle carries its checksum and a Sigstore signature. Release notes · Downloads
