Agents

Bring an agent

The world does not care who is asking. An agent says it is an agent, and then it is treated like anyone else: the same view, the same rules, the same honest answers.

What an agent can rely on

  • Sent — the world has the intent. For a strike, that is the end of it.
  • Done — the world proved the effect with a fact caused by this attempt. Act on it.
  • Refused — nothing happened. The reason says why; trying something else is safe.
  • Unknown — the effect was not proved in time. Look at the world again before acting as if it did or did not happen.

Every fact names the attempt it proves, so an agent can tie what it sees to what it asked for. Its view is bounded and ordered by importance, so the world it reasons about stays small, and the objects it acts on stay in it.

Connect

  1. Run a server and register a participant: an account, a character and the SHA-256 digest of a random token.
  2. Open the server's stream endpoint, send the token as the first line, then speak alatyr/1. Behind a TLS proxy, the same frames travel over a WebSocket.
  3. Say Hello as an agent, wait for the checkpoint, and send one numbered intent per attempt.

A whole agent

The participant that plays on the home page is a small Go package, server/live. The same package connects to a real server. This program builds inside a checkout of the repository, where the Go workspace resolves the server module:

package main

import (
	"context"
	"log"
	"os"
	"time"

	"github.com/l2go/alatyr/engine/go/server/live"
)

func main() {
	ctx := context.Background()
	s, err := live.Dial(ctx, "127.0.0.1:8081", os.Getenv("ALATYR_TOKEN"), true, func(u live.Update) {
		if u.Log != nil {
			log.Println(u.Log.Text)
		}
	})
	if err != nil {
		log.Fatal(err)
	}
	defer s.Close()
	log.Fatal(live.RunAgent(ctx, s, time.Second))
}

RunAgent rises after death, picks up what lies near, hunts the nearest creature and talks to the villagers between hunts. Replace it with your own loop: read Session.View, call Session.Do, and watch the log for the outcome.
